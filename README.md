# Sonsuz Otobüs Bekleyicisi

## Bu Ne?

Bu repository, dünyanın en gereksiz, en absürt ve en felsefi otobüs bekleme simülatörüdür.

Otobüs **asla** gelmez. Ama siz beklersiniz. Ve beklersiniz. Ve beklersiniz.

## Neden Var?

Çünkü bazen kod yazmak yerine otobüs beklemek daha anlamlıdır.
Bu proje, o anlamı bilimsel olarak ispatlar.

## Nasıl Çalışır?

```bash
python otobus_bekleyici.py
```

Çalıştırın. Özürler okuyun. Felsefe yapın. Otobüs gelmeyecek.

## Özellikler

- Rastgele Türkçe özürler
- Derin felsefi düşünceler
- Gerçekçi 0.5 saniye bekleme simülasyonu
- Sonsuzluk kavramının pratik sınırları

## Lisans

Otobüs gelene kadar MIT. Otobüs gelince yeniden düşünülür.

## Katkıda Bulunma
